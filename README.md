# Модуль фитнес-трекера

Модуль состоит из двух пакетов. 

1. Пакет daysteps отвечает за учёт активности в течение дня. Он собирает переданную информацию в виде строк, парсит их и выводит информацию о количестве шагов, пройденной дистанции и потраченных калориях.
2. Второй пакет spentcalories также обрабатывает переданную информацию и рассчитывает потраченные калории в зависимости от вида активности — бега или ходьбы. И тоже возвращает информацию обо всех тренировках.
